## 简介
GlowstoneLauncher 是一款基于 C# WPF 开发的 Minecraft Java 启动器，主打国内网络环境优化，简化游戏版本管理流程。
专为 Windows 平台打造，使用自研下载方案，依托国内镜像大幅提升资源下载速度。

## 功能特性
### 核心功能
- 版本管理：一键安装原版、Forge、Fabric 等主流加载器，自由切换
- Java 自动检测：缺失时自动下载配置对应Java，无需手动折腾
- 账户支持：微软正版账号 + 离线账号+外置登录
- 内置更新：程序自动检测新版本，支持GitHub更新通道

### 模组与资源
- 模组管理：本地模组浏览、删除，对接Modrinth、CurseForge资源库
- 3D皮肤预览：支持玩家皮肤带动画实时预览
